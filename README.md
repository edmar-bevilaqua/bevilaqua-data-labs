# Bevilaqua Data Labs

Website institucional da Bevilaqua Data Labs, desenvolvido com React, TypeScript, Vite, Tailwind CSS e componentes shadcn/ui.

O projeto reposiciona o antigo portfólio pessoal como uma presença corporativa bilíngue para comunicar serviços, labs técnicos, contato institucional, suporte e política de privacidade.

## Tecnologias

- Vite
- TypeScript
- React
- Tailwind CSS
- shadcn/ui
- EmailJS

## Desenvolvimento local

```sh
npm install
npm run dev
```

## Scripts

- `npm run dev`: inicia o servidor de desenvolvimento.
- `npm run build`: gera a versão de produção.
- `npm run lint`: executa o ESLint.
- `npm run preview`: pré-visualiza o build localmente.
- `npm run deploy`: publica o diretório `dist` via GitHub Pages.

## Estrutura principal

- `src/content/siteContent.ts`: copy bilíngue do site.
- `src/pages/Index.tsx`: landing page institucional.
- `src/pages/Privacy.tsx`: política de privacidade.
- `src/pages/Support.tsx`: página de suporte.
- `src/components`: seções e componentes visuais reutilizáveis.
